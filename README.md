Sakala's Online Clinic

1. Project Overview

Sakala's Online Clinic is a simple multi-page healthcare website developed using HTML. The purpose of the website is to provide users with information about available medical services, doctors, appointments, and contact details.

The website was designed with a simple and user-friendly structure, with separate pages connected through navigation links.

Main Pages

The project contains the following HTML pages:

- "index.html" – Home page
- "doctors.html" – Doctors and medical professionals
- "appointment.html" – Appointment booking
- "services.html" – Medical services offered
- "contact.html" – Contact information and communication form

The pages are connected using HTML hyperlinks so that users can move from one page to another.

Question: Which three elements were most important for structuring the content and why?

The three most important elements were "<header>", "<nav>", and "<main>".

- "<nav>" provided links that allowed users to move between the different pages.
- "<main>" separated the main information from the header and footer and made the structure easier to understand.

3. HTML Attributes

3.1 Attributes Used

The website uses more than the required 15 HTML attributes.But the 3 essentialwere;


"id"| Identifies a specific element
"lang"| Defines the language of the document
"charset"| Defines the character encoding

Question: How did you use the "class" and "id" attributes differently?

The "class" attribute was used to identify groups of elements that could have similar properties or styling.

The "id" attribute was used to uniquely identify a particular element or section on a page.

For example, several elements can have the same class, while an "id" should normally identify one specific element.

Question: Which attribute helped improve user experience the most and why?

The "alt" attribute was particularly useful because it provides alternative text when an image cannot be displayed. It also makes the website more accessible to users who rely on screen readers.

The "href" attribute was also very important because it allowed users to navigate between the different pages of the website.

4. Development Process

4.1 How did you plan your website structure before coding?

Before starting the coding process, I first identified the main information that an online clinic website would need.

I divided the website into different pages:

1. Home page
2. Doctors page
3. Services page
4. Appointment page
5. Contact page

I then planned the navigation system so that users could easily move from one page to another.

After planning the structure, I created the HTML files and started adding the required content and HTML elements.

---

4.2 Development process

The website was developed step by step.

Step 1 – Create the Project Folder

A main project folder was created to contain all the website files.

Step 2 – Create the HTML Pages

The main HTML files were created:

index.html
doctors.html
services.html
appointment.html
contact.html

Step 3 – Create the Navigation

Navigation links were added to allow users to move between the different pages.

Example:

<nav>
    <a href="index.html">Home</a>
    <a href="doctors.html">Doctors</a>
    <a href="services.html">Services</a>
    <a href="appointment.html">Appointment</a>
    <a href="contact.html">Contact</a>
</nav>

Step 4 – Add Content

Headings, paragraphs, lists, tables, images, forms, buttons, and other HTML elements were added to the pages.

Step 5 – Add Images

Relevant images were added using the "<img>" element.

Step 6 – Create Forms

Forms were created for collecting information such as appointment and contact details.

Step 7 – Test the Website

Each page was opened in a web browser to check the links, images, forms, and overall structure.

Step 8 – Debug Errors

Errors such as incorrect links, missing images, and incorrectly written HTML tags were identified and corrected.

Step 9 – Upload to GitHub

The completed project files were added to Git and pushed to a GitHub repository.
